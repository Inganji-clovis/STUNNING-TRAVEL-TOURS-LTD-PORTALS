# Application Structure: Stunning Travel & Tours Portal

This document outlines the core directory structure and the purpose of key files in the standalone Dockerized application.

## 📂 Root Directory
- **`docker-compose.prod.yml`**: The main configuration file for the production Docker stack (App, Web, Database).
- **`nginx-proxy-manager-stack.yml`**: Configuration for the SSL and Proxy management service.
- **`launcher.ps1`**: The primary entry point for users. A PowerShell script that manages the Docker lifecycle and launches the app window.
- **`Dockerfile`**: Defines the PHP 8.3 environment used by the application container.
- **`.env`**: (Ignored by Git) Contains environment-specific configurations like database passwords.
- **`README.md`**: Project overview.

## 📂 `docker/`
Contains service-specific configuration files.
- **`docker/nginx/default.conf`**: Custom Nginx configuration for the Laravel application.

## 📂 `public/`
The web-accessible directory.
- **`public/assets/brand/`**: Contains logos and branding images (e.g., `new-logo.png`).
- **`public/favicon.ico`**: The application icon used by browsers and shortcuts.

## 📂 `app/`, `bootstrap/`, `config/`, `routes/`, `database/`
Standard Laravel internal directories containing the backend logic, models, controllers, and database migrations.

## 📂 `resources/`
Contains frontend assets like Blade templates and CSS.
